# 1v1

Improve your goal scoring instincts with simulation training for one vs one situations against a goalkeeper. 

## Overview

1v1 is a browser soccer training app focused on finishing in 1v1 scenarios. It provides a visual, interactive environment for practicing decision-making, shot selection, and goalkeeper reading in both augmented reality and simulation modes. 
The app aims to improve your instinctual finishing ability.  


## Features

- **Two training modes**
  - **AR mode** for goalkeeper positioning and target selection
  - **Simulation mode** for tactical shot placement and outcome tracking
- **Decision quality**
  - **Metrics**
  - **Analysis**
  - **Improvement suggestions**
- **Interactive goal zones** 
- **Goalkeeper positioning and behavior controls**
- **Session statistics**
  - Goals scored
  - Saves
  - Misses
  - Decision quality metrics
- **Mobile-friendly UI**
  
## Tech Stack

- **HTML**
- **CSS**
- **JavaScript** 

## Getting Started

Because this is a static HTML project, you can run it directly in a browser.

### Option 1: Open locally
1. Clone the repository.
2. Open `1v1-trainer.html` in your browser.
